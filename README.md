## 🏢 About Studio Tech Fusion

**Studio Tech Fusion** is a software studio in Dhaka, Bangladesh, founded in 2026. We do two things:

1. **Build our own AI products** for shops, agencies and teams.
2. **Build custom software for clients** in Switzerland, Malaysia, Bangladesh and beyond: e-commerce, corporate websites, charity platforms, ERPs and mobile apps.

As Founder & CEO I lead product, architecture and engineering, and I write a lot of the code myself, working with AI coding agents (Claude Code) across the whole stack.

---

## 🚀 Products I'm building

| Product | What it is | Stack |
|---|---|---|
| **Agentic POS** | Offline-first, multi-tenant B2B point-of-sale SaaS for small retail and grocery shops, with an AI assistant built in. | React 19 · Vite PWA · Hono · Drizzle · MySQL · Better-Auth · Vercel AI SDK |
| **Fusion Bot** & **Fusion Bot Cloud** | A local-first chat app where every contact is an AI agent with its own personality, model, memory, tools and connected apps. The Cloud edition gives each user an isolated hosted instance, with a portal, desktop app and Android app. | TypeScript · React · Electron · Node · Docker |
| **Studio Tech Fusion ERP / CRM** | Our internal business system: customers, projects, tasks, quotations, invoices, payments, finance, hosting and a client portal. It includes an **MCP server**, so AI assistants like Claude can work in the CRM directly. | Laravel 11 · Next.js · MySQL · MCP |
| **FusionPanel** *(in planning)* | A multi-server hosting control panel (admin, reseller and client levels) with a built-in security suite. | HestiaCP API · TypeScript |

> Most product code is private. Ask me for a demo or visit [studiotechfusion.com](https://studiotechfusion.com).
